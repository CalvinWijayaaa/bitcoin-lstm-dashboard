Bitcoin AI

Artificial Intelligence Based Prediction System

Predicting the next-day Bitcoin price using Long Short-Term Memory (LSTM) and historical BTC-USD market data.

📌 About This Project

This application was developed to predict the next-day Bitcoin price using the Long Short-Term Memory (LSTM) algorithm. The prediction model is trained using historical BTC-USD data obtained from Yahoo Finance and presented through an interactive web dashboard.

🧠 Machine Learning Model

Algorithm LSTM (Long Short-Term Memory)
Dataset BTC-USD Yahoo Finance
Window Size 60 Days
Epoch 50
Features Open, High, Low, Close, Volume
Optimizer Adam (Adaptive Moment Estimation)
Loss Function Mean Squared Error
Output Next-Day Bitcoin Price
